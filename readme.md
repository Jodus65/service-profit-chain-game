## 🏨 情境背景與個案故事

### 蘭陽平原的溫泉明珠陷入「失敗循環」
坐落於宜蘭礁溪核心美人湯泉景區的 **Grand Jodus 連鎖星級飯店（礁溪旗艦會館）**，原本以溫潤細緻的在地款待文化與高品質服務聞名。然而，三年前跨國投資基金入主接管後，新任管理層為了追求短期季度財報獲利，採取了極端的**「控本策略」**：
* 大幅解雇熟悉在地客群的資深溫泉幹部與領班；
* 將一線基層薪資壓制在業界最低水準；
* 全面取消星級款待培訓以節省經常性開銷；
* 收回第一線員工的現場處置授權以防範資源浪費。

### 初始營運慘況（第 0 季度基準線）
短期內帳面支出雖然被壓低，但服務品質與員工士氣隨即發生雪崩：
* **基層員工年流動率**：高達 **112.4% ～ 140%**，常態缺工 30%；
* **顧客滿意度 (CS)**：跌至低谷 **42.1 / 100**，客訴與一星負評不斷；
* **單季營業損益**：虧損高達 **NT$ -2,485,000**；
* **顧客回頭率**：僅剩 **17.7%**，深陷典型的「失敗循環（Cycle of Failure）」。

**您的總經理任務：**
您受聘接掌 Grand Jodus 礁溪會館，必須在四個季度的任期內重新分配資源，透過優化人力資源投資，帶領團隊走出泥潭、轉虧為盈，啟動「成功循環（Cycle of Success）」！

## ⚙️ 遊戲核心機制與決策變數

學員每季必須針對三大關鍵人力資本投資進行預算拉桿（Slider）配置（數值範圍 0 ～ 100）：

| 決策變數 | 意涵與現實對應 | 決策兩難（Trade-off） |
| :--- | :--- | :--- |
| **薪資福利結構 (C)**<br>*(Compensation)* | 基層薪酬、伙食補貼、三節獎金與勞動條件。 | **提高**能立即降低流動率、提振滿意度，但會大幅增加當季固定成本；<br>⚠️ **嚴禁降薪**：調降薪資會觸發「損失規避」心理，滿意度將遭受 **1.8 倍** 的報復性暴跌。 |
| **教育訓練投入 (T)**<br>*(Training)* | 美人湯服務 SOP、心理韌性、高階客訴溝通認證。 | 投資教育訓練需要**時間發酵（Time Lag）**，當季財報無法立刻見效；但它是解鎖「第一線授權」發揮正面效益的必備基石。 |
| **第一線員工授權 (E)**<br>*(Empowerment)* | 員工在面對客怨時的即時免單、補償與驚喜預算額度。 | **無培訓的盲目授權是災難**（當 $T < 40$ 且高 $E$，會導致公款濫用與顧客反感）；唯有搭配高規格訓練（$T \ge 40$），高授權才能創造超越預期的感動服務。 |

### 關鍵時刻（Moments of Truth, MOT）隨機突發事件
在推進季度時，系統將隨機觸發高度真實的管理衝突事件，檢驗學員的前線應變策略：
1. **Q1 VVIP 紅酒污漬危機**：高價值商務顧客在宴會廳被紅酒濺污洋裝，考驗現場即時服務補救能力（若先前未配置足夠培訓與授權，高階補救方案將直接被鎖定）。
2. **Q2 前線嚴重過勞潮**：缺額引發基層集體罷工怠工危機，考驗在營運負載、加班補貼與員工心理之間的取捨。
3. **Q3 競爭對手高薪挖角戰**：鄰近新開的頂級溫泉渡假酒店開出高薪挖角骨幹，考驗長期留任計畫與激勵機制設計。

## 🏆 勝負標準與年度評級體系

第四季度結束時，董事會將依據**累計損益**、**最終員工流動率**與**顧客滿意度**進行綜合任免考核：

* 🏆 **S 級（傳奇總經理）**：
  * **門檻**：年度累計損益 $>$ NT$ 1,500,000、流動率 $<$ 40%、顧客滿意度 $>$ 80 分。
  * **評語**：完美踐行服務利潤鏈，成功創造指數級的顧客忠誠複利，實現在地名利雙收。
* 🌟 **A 級（卓越經理人）**：
  * **門檻**：累計損益沖銷前期赤字（損益 $>$ -NT$ 1,500,000）、顧客滿意度 $>$ 70 分、流動率 $<$ 60%。
  * **評語**：頂住前期財務赤字壓力，扎實打好團隊根基，第四季成功反轉局勢。
* 💼 **B 級（平庸守成者）**：
  * **門檻**：滿意度 55 ～ 70 分，流動率仍徘徊在 60% ～ 90%。
  * **評語**：策略搖擺保守、吝於投資員工體驗，無法啟動成功循環，收獲平庸回報。
* 🚨 **F 級（失敗循環泥潭）**：
  * **門檻**：指標未能改善，巨額赤字持續擴大，流動率仍突破 90%。
  * **評語**：短視近利，持續陷入「苛扣成本 $\rightarrow$ 人才流失 $\rightarrow$ 品質劣化 $\rightarrow$ 虧損加劇」的死亡螺旋。

> 💡 **破解迷思：全部調到最高（100 / 100 / 100）可以通關嗎？**  
> **絕對不行！** 過度投資會造成邊際效益遞減，第一季固定開銷暴增會引發難以挽回的資金斷裂，導致累計赤字過大而無法晉身 S 級。最優解是一套**「先止血（高C、中T、低E） $\rightarrow$ 穩陣腳 $\rightarrow$ 再授權收割忠誠複利」**的節奏性配置。

## 🎮 學員四季度遊玩指南

1. **第一步：閱讀首頁任務**
   點開遊戲網址，閱讀 Grand Jodus 礁溪會館的危機背景與三大任務，點擊**「接受委任，即刻入主」**進入策略主控台。
2. **第二步：平衡預算滑桿**
   依據當季情勢拉動「薪資福利 (C)」、「教育訓練 (T)」與「員工授權 (E)」，下方會動態預估當季人資支出。
3. **第三步：應對 MOT 突發危機**
   點擊「提交策略」，系統將彈出當季的突發營運危機，從中挑選最適處置方案。
4. **第四步：檢視季度報表與理論回饋**
   彈出視窗將分析當季損益、流動率與市場評語，並提供對應的哈佛服務利潤鏈學術點評。
5. **第五步：四季總結與覆盤截圖**
   完成第四季度後，系統將結算年度綜合報告，並自動產生**「四季策略軌跡與數據對比覆盤表」**。請學員截圖此頁面，作為課堂討論與作業依據。

## 🚀 1 分鐘免費部署至 GitHub Pages

這款遊戲設計為單純的前端應用程式，免裝 Node.js、免後端，任何人都可以 1 分鐘上線：

### 步驟 1：建立公開 Repository
1. 登入 [GitHub](https://github.com/)。
2. 點擊右上角 **「+」** $\rightarrow$ **「New repository」**。
3. 輸入 Repository 名稱（例如：`grand-jodus-sim`）。
4. 選擇 **Public**（公開才能享有免費靜態託管），點擊 **Create repository**。

### 步驟 2：上傳 `index.html`
1. 在剛建立好的 Repository 頁面中，點擊 **「uploading an existing file」**。
2. 將本專案的 **`index.html`** 直接拖曳進去。
   * ⚠️ **重要提醒**：檔案名稱請務必全小寫命名為 `index.html`。
3. 點擊下方綠色的 **「Commit changes」**。

### 步驟 3：開啟 GitHub Pages 服務
1. 點擊倉庫頂部的 **「Settings」**（齒輪圖示）。
2. 在左側欄位點擊 **「Pages」**（位於 Code and automation 區塊）。
3. 在 **Branch** 下拉選單中：
   * 將 `None` 改選為 **`main`**（或 `master`）。
   * 資料夾保持預設的 **`/(root)`**。
   * 點擊 **Save**。
4. 等候約 30 秒至 1 分鐘，重新整理頁面，頂部即會出現專屬網址：
   > **`https://<你的GitHub帳號>.github.io/<專案名稱>/`**

學員只要用任何裝置點開該網址即可直接開始遊玩！

## 🎓 MBA 課堂引導與覆盤討論指引

建議安排 15 ～ 20 分鐘遊玩，接著進行 20 ～ 30 分鐘的個案覆盤討論：

1. **時間滯後（Time Lag）的焦慮**：
   * *問學員*：「在 Q1 大舉調薪、增加訓練時，當季財報表現如何？」
   * *理論點評*：人力資本投資是資本支出，效益需要時間蓄積。短視的經理人往往因為抗拒 Q1 的帳面赤字，中途放棄投資，從而永遠被鎖死在失敗循環中。
2. **損失規避（Loss Aversion）的代價**：
   * *問學員*：「有沒有組別在 Q2 或 Q3 嘗試調降薪資（降低 C）？發生了什麼事？」
   * *理論點評*：拿走既有福利帶來的痛苦感是獲得快樂的 2 倍以上。薪資具備強烈向下剛性，降薪引發的「無聲罷工」與流動率反彈，會造成更高的隱性招募損失。
3. **授權與培訓的交互作用（Interaction Effect）**：
   * *問學員*：「為什麼在沒有培訓時給予高授權，反而造成顧客不滿與高額虧損？」
   * *理論點評*：授權是武器，培訓是準星。未受訓員工拿到高額處置權只會盲目免單、敷衍塞責；唯有經過高規格訓練的同仁，才能把授權化為創造驚喜與感動的工具。
